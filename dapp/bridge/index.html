      How it works

      Two chains, one state

      Each chain’s state is proven to the other in zero knowledge. A bridge waits for a proof, never for a signature.

      • No federation
      • No multisig
      • No soft fork
      • Live on mainnet
      01 · The note

      One note, two chains

      A Tacit note is a Pedersen commitment on secp256k1, the curve both chains already use. The same commitment is the note on Bitcoin and in the pool on Ethereum, so a bridge moves the note without opening it.

      C = v·H + r·G · amount v hidden, blinding r known to its owner alone

      02 · Bitcoin → Ethereum

      Bitcoin, proven on Ethereum

      1. Headers, by workA permissionless relay on Ethereum checks every Bitcoin header’s proof of work. The heaviest chain wins.
      2. Every envelope foldedA program re-hashes each block to its Merkle root and folds every Tacit envelope in it: transfers, trades, burns, locks.
      3. One proofSP1 proves the fold. Its tip must sit 24 blocks under the relay’s.
      4. Checked by the poolThe pool verifies the proof against a pinned key, then mints each proven burn once, keyed by its burn id.
      Proven to block
      03 · Ethereum → Bitcoin

      Ethereum, proven back

      1. Finality, signedEthereum’s sync committee signs each finalized block. A light client checks the signatures, period after period, from a pinned anchor.
      2. The pool’s storageStorage proofs against the finalized state root read the pool’s cross-outs, the notes it consumed, and its outbox.
      3. Inside Bitcoin’s proofThe Bitcoin program verifies the Ethereum proof recursively. One proof carries both chains.
      4. Folded on BitcoinA crossed-out note is minted on Bitcoin only if its claim is a member of the proven set, and only once.
      Proven to Ethereum block
      04 · Trust

      Who checks what

      Every hop of a bridge is checked by math anyone can rerun.

      No multisig, federation or attestor set signs a bridge message. Anyone can run the provers.

      Proof of work

      Every header’s work is checked on Ethereum by a permissionless relay. Bitcoin’s proof must sit 24 blocks deep; a deeper reorg halts reflection rather than rewriting it.

      The sync committee’s signatures

      Checked inside the proof by a light client built on sp1-helios, chained period to period from a pinned anchor, and bound to Ethereum’s genesis so no other chain’s proof passes.

      An immutable contract

      Every proof is verified on Ethereum against pinned verifying keys. Nobody can change them.

      Bitcoin reflection 0x00bb158b…074bc5

      Bitcoin orders, the rules decide

      Ops ride in Taproot witnesses. Every indexer that runs the same rules over the same chain reaches the same state, and the reflection proves that state.

      Reproducible programs

      Each program rebuilds byte for byte from source and is pinned by SHA-256 to its verifying key.
